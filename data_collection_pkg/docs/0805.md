# Real Robot Validation Checklist

This package is prepared as a standalone ROS2 `ament_python` package named
`data_collection_pkg`. Place the whole directory under a ROS2 workspace `src/`
folder, build it, and run the checks below on the robot or URSim integration
machine.

## 1. Build And Source

```bash
cd ~/ur5e_ws
colcon build --symlink-install --packages-select data_collection_pkg
source install/setup.bash
```

Confirm command entry points:

```bash
ros2 run data_collection_pkg data_collection list-schemas
ros2 pkg executables data_collection_pkg
```

## 2. Confirm Runtime Topics

Required teleoperation inputs:

```text
/joint_states                         sensor_msgs/msg/JointState
/teleop/command                       std_msgs/msg/Float64MultiArray
/gripper/state                        std_msgs/msg/Float64MultiArray
```

Recommended inputs:

```text
/camera2/scene_camera/color/image_raw/compressed      sensor_msgs/msg/CompressedImage
/camera1/wrist_camera/color/image_raw/compressed      sensor_msgs/msg/CompressedImage
/safety/state                         std_msgs/msg/String
/tool0/pose                           geometry_msgs/msg/PoseStamped
```

Check them before recording:

```bash
ros2 topic info /joint_states
ros2 topic info /teleop/command
ros2 topic info /gripper/state
ros2 topic echo /joint_states --once
```

If your real topics differ, pass remaps or override collector message-type
parameters in the launch/run command instead of changing package code.

## 3. Record One Short Teleop Episode

```bash
ros2 run data_collection_pkg data_collection_collector_node --ros-args \
  -p root:=/tmp/ur5e_datasets \
  -p task:=teleop_pick \
  -p dataset_schema:=teleop_twist_gripper \
  -p max_sync_delta_s:=0.07
```

In a second terminal:

```bash
ros2 topic echo /data_collection/quality_status
ros2 topic echo /data_collection/drop_reason
```

Operate the robot at low speed for a short episode, then stop the collector.

## 4. Gate The Recorded Dataset

```bash
ros2 run data_collection_pkg data_collection quality-check \
  /tmp/ur5e_datasets/trainable/teleop/twist_gripper \
  --profile trainable \
  --required-camera external \
  --required-camera wrist \
  --max-sync-delta-s 0.07 \
  --target-fps 10.0 \
  --fps-tolerance-ratio 0.2 \
  --min-frame-count 20 \
  --min-duration-s 2.0 \
  --require-ee-pose
```

The command must return `"ok": true` before the episode is used for training.
If it fails, inspect `issues` first; the package records exact quality failures
such as missing camera frames, stale topics, unsafe status, schema mismatch, or
timestamp jitter.

## 5. Clean And Review Original Qpos Captures

For fixed-rate captures under `original/<mode>/qpos_gripper`, select the
completed capture in the Qt panel and press `Clean Data`. The panel requires a
confirmation before it replaces the sibling `cleaned/<mode>/qpos_gripper`
output. It does not modify original frames, images, metadata, or annotations.

The same operation is available without the panel:

```bash
ros2 run data_collection_pkg data_collection clean-original \
  /tmp/ur5e_datasets/original/teleop/qpos_gripper
```

Open `cleaned/teleop/qpos_gripper/meta/cleaning_report.html`. Every rejected
episode must list a concrete reason. `needs_review` means the episode passed
technical checks but lacks a valid human `success` annotation, so it is not
included in the cleaned training dataset. Replay an accepted cleaned episode
before export.

## 6. Convert To LeRobot

Install optional training dependencies first:

```bash
cd ~/ur5e_ws/src/data_collection_pkg
python3 -m pip install --user --upgrade -r requirements-lerobot.txt
```

Verify that the official exporter and its runtime dependencies are importable
before starting conversion:

```bash
python3 - <<'PY'
import datasets
import pyarrow
import torch
from lerobot.datasets.lerobot_dataset import LeRobotDataset

print("torch", torch.__version__)
print("datasets", datasets.__version__)
print("pyarrow", pyarrow.__version__)
print("LeRobotDataset", LeRobotDataset.__name__)
PY
```

If this command fails, do not start conversion. Resolve the missing Python
package in the same interpreter used by `ros2 run` first.

Convert:

```bash
ros2 run data_collection_pkg data_collection convert-jsonl-to-lerobot \
  /tmp/ur5e_datasets/cleaned/teleop/qpos_gripper \
  --output-dir /tmp/ur5e_lerobot_official \
  --repo-id local/ur5e_teleop \
  --fps 15 \
  --camera pano=external \
  --camera wrist \
  --visual-storage video \
  --video-codec h264
```

The output path and `repo-id` are independent. The current v3 export stores
each camera as H.264 MP4 under `videos/`; Parquet stores state, actions, and
video time indices rather than image bytes.

Open official visualization when available:

```bash
ros2 run data_collection_pkg data_collection lerobot-viz \
  --dataset-dir /tmp/ur5e_datasets/cleaned/teleop/qpos_gripper \
  --dataset-kind jsonl \
  --output-root /tmp/ur5e_lerobot_official \
  --repo-id local/ur5e_teleop \
  --episode-index 0 \
  --fps 10.0 \
  --camera external \
  --camera wrist
```

## 7. Validate Replay In URSim/RViz

Do not replay to a real robot from this package. The included replay path is
simulation-safe by default and publishes `execute_real=false`.

```bash
ros2 launch data_collection_pkg data_collection_replay.launch.py \
  dataset_dir:=/tmp/ur5e_datasets/cleaned/teleop/qpos_gripper \
  episode_index:=0 \
  rate_hz:=10.0 \
  sim_command_topic:=/ur_control/sim/replay_command \
  frame_id:=base
```

Expected topics:

```bash
ros2 topic echo /data_collection/replay/status
ros2 topic echo /data_collection/replay/action
ros2 topic echo /ur_control/sim/replay_command
```

In RViz, add a Marker display for `/data_collection/replay/marker`.

## Acceptance

The package is considered integration-ready when:

- `colcon build --packages-select data_collection_pkg` passes.
- `data_collection list-schemas` prints schemas.
- Topic monitor shows required streams active.
- A real teleop episode is recorded.
- `quality-check --profile trainable` returns `ok: true`.
- JSONL-to-LeRobot conversion succeeds.
- URSim/RViz replay publishes simulation-safe commands and marker output.
