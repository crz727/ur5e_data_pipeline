# Changelog

## v0.1.0

- Added ROS 2 fixed-rate UR5e qpos collection with scene-camera timestamp anchoring.
- Added independent teleop, HTTP, ACT, and VLA capture classifications.
- Added synchronization tolerances for cameras, joint states, and binary gripper state.
- Added dataset annotation, cleaning audit, resume capture, and LeRobot v3 export workflows.
- Added native Qt5/RViz2 panel integration with Dashboard API and control-mode manager.
- Added safe replay topics, replay TF isolation, and live-topic replay blocking.
- Published only the two project packages and repository-level documentation; build outputs, datasets, and planning notes are excluded.
